# Manual Tests — 2026-06-17

## 1. Отпуск — Навигация и общий вид

### TC-1.1 Открытие экрана отпусков из главного экрана года
1. Запустите приложение. Дождитесь загрузки главного экрана года (год в заголовке).
2. Нажмите на кнопку **«Отпуск»** (иконка в верхнем правом углу, рядом с шестерёнкой настроек).
3. **Ожидаемый результат:** Откроется экран «Отпуск». Заголовок по центру — «Отпуск». В левом верхнем углу кнопка «Назад» (стрелка). В правом нижнем углу — круглая кнопка «+». Если отпусков нет, в центре экрана отображается текст «Отпусков пока нет. Нажмите + чтобы добавить.»

### TC-1.2 Возврат на главный экран года
1. Откройте экран «Отпуск» (см. TC-1.1).
2. Нажмите кнопку **«Назад»** (стрелка в левом верхнем углу).
3. **Ожидаемый результат:** Возврат на главный экран года. Месяцы отображаются как раньше.

### TC-1.3 Возврат аппаратной кнопкой «Назад» (Android)
1. Откройте экран «Отпуск».
2. Нажмите аппаратную кнопку **«Назад»** на телефоне.
3. **Ожидаемый результат:** Возврат на главный экран года.

## 2. Отпуск — Создание нового отпуска

### TC-2.1 Открытие формы добавления отпуска
1. Откройте экран «Отпуск».
2. Нажмите круглую кнопку **«+»** в правом нижнем углу.
3. **Ожидаемый результат:** Откроется форма «Новый отпуск». Заголовок по центру — «Новый отпуск». Поля: «Дата начала» (подсказка DD.MM), «Дата окончания» (подсказка DD.MM), «Дней» (поле ввода и кнопка «+»), «Цвет» (6 цветных кружков). Кнопки: «Сохранить» и «Отмена». Кнопка «Сохранить» неактивна (полупрозрачная).

### TC-2.2 Создание отпуска — базовый сценарий (один день)
1. Откройте форму нового отпуска (TC-2.1).
2. В поле «Дата начала» введите: `14.07`
3. В поле «Дата окончания» введите: `14.07`
4. В поле «Дней» должно отобразиться: `1`
5. **Ожидаемый результат:** В карточке предпросмотра отображаются «Рабочих дней» и «Всего дней» (значения зависят от типа дня 14 июля — рабочий или выходной).
6. Нажмите кнопку **«Сохранить»**.
7. **Ожидаемый результат:** Форма закрывается. На экране «Отпуск» появляется карточка с датами `14.07.2026 — 14.07.2026` и подписью `X / Y` (рабочие / всего).

### TC-2.3 Создание отпуска — несколько рабочих дней
1. Откройте форму нового отпуска.
2. В поле «Дата начала» введите: `07.07`
3. В поле «Дата окончания» введите: `11.07`
4. В поле «Дней» должно отобразиться: `5`
5. **Ожидаемый результат:** Предпросмотр показывает рабочих дней (включая сокращённые) и всего дней. Для недели 07-11 июля 2026 (пн-пт) — должно быть 5 рабочих / 5 всего.
6. Нажмите **«Сохранить»**.
7. **Ожидаемый результат:** Карточка отпуска появилась в списке с диапазоном `07.07.2026 — 11.07.2026`.

### TC-2.4 Отпуск с выходными днями включёнными
1. Откройте форму нового отпуска.
2. Введите дату начала: `11.07` (суббота).
3. Введите дату окончания: `13.07` (понедельник).
4. **Ожидаемый результат:** В поле «Дней» отображается `3`. Предпросмотр: рабочих дней = 1 (только 13.07), всего дней = 3.
5. Сохраните.
6. **Ожидаемый результат:** Карточка отпуска отображает `1 / 3`.

### TC-2.5 Отпуск через праздники
1. Откройте форму нового отпуска.
2. Введите дату начала: `31.12`
3. Введите дату окончания: `08.01`
4. **Ожидаемый результат:** Кнопка «Сохранить» активна. Предпросмотр корректно считает рабочие и выходные/праздничные дни (31.12 — рабочий, 01.01 — праздничный, и т.д.).
5. Сохраните.

### TC-2.6 Выбор цвета отпуска
1. Откройте форму нового отпуска.
2. Введите валидные даты (например, `07.07` — `11.07`).
3. Обратите внимание на секцию «Цвет». По умолчанию выбран бирюзовый (Teal, `#2DD4BF`) — он обведён рамкой.
4. Нажмите на **синий кружок** (Blue).
5. **Ожидаемый результат:** Синий кружок обведён рамкой, бирюзовый больше не обведён.
6. Нажмите на **фиолетовый кружок** (Purple).
7. **Ожидаемый результат:** Фиолетовый обведён рамкой.
8. Сохраните.
9. **Ожидаемый результат:** В списке отпусков у карточки цветная полоса слева — фиолетовая.

## 3. Отпуск — Ввод дат: форматирование и валидация

### TC-3.1 Автоматическое добавление точки-разделителя
1. Откройте форму нового отпуска.
2. В поле «Дата начала» введите: `1407` (без точки).
3. **Ожидаемый результат:** Поле автоматически отформатируется как `14.07`. Точка вставляется после двух цифр дня.

### TC-3.2 Ограничение ввода — максимальная длина
1. В поле «Дата начала» попробуйте ввести длинную последовательность цифр: `14072026`
2. **Ожидаемый результат:** Поле принимает максимум 5 символов (`DD.MM`), лишние цифры не вводятся.

### TC-3.3 Ввод недопустимого дня (>31)
1. В поле «Дата начала» введите: `32`
2. **Ожидаемый результат:** Поле не даёт ввести день 32. После ввода `3` вторая цифра отбрасывается (или поле обрезается до одной цифры).

### TC-3.4 Ввод недопустимого месяца (>12)
1. В поле «Дата начала» введите: `14.13`
2. **Ожидаемый результат:** Месяц `13` не принимается. Вторая цифра месяца отбрасывается — поле остаётся `14.1`.

### TC-3.5 Ввод несуществующей даты (30 февраля)
1. В поле «Дата начала» введите: `30.02`
2. **Ожидаемый результат:** Дата 30 февраля не является валидной. Поле отображает `30.02`, но при попытке распознать дату она не валидна (кнопка «Сохранить» остаётся неактивной, если поле «Дата окончания» тоже не заполнено). Если поле окончания заполнено — отображается сообщение об ошибке или кнопка остаётся неактивной.

### TC-3.6 Ввод несуществующей даты (31 апреля)
1. В поле «Дата начала» введите: `31.04`
2. **Ожидаемый результат:** 31 апреля не существует. Аналогично TC-3.5 — дата не распознаётся как валидная.

### TC-3.7 Поле «Дата окончания» — автозаполнение при вводе дней
1. Откройте форму нового отпуска.
2. В поле «Дата начала» введите: `07.07`.
3. В поле «Дней» введите: `5`.
4. **Ожидаемый результат:** Поле «Дата окончания» автоматически заполняется как `11.07` (07.07 + 5 дней - 1 = 11.07).

### TC-3.8 Изменение даты начала пересчитывает дату окончания
1. В поле «Дата начала» введите: `07.07`.
2. В поле «Дней» введите: `5`.
3. Дата окончания: `11.07`.
4. Измените поле «Дата начала» на: `10.07`.
5. **Ожидаемый результат:** Дата окончания автоматически пересчитывается на `14.07` (10.07 + 5 - 1 = 14.07). Поле «Дней» остаётся `5`.

### TC-3.9 Кнопка «+» рядом с полем «Дней» — инкремент
1. В поле «Дата начала» введите: `07.07`.
2. Поле «Дней» пустое (или `0`). Кнопка «+» рядом с полем «Дней» неактивна (полупрозрачная).
3. В поле «Дней» введите: `3`.
4. Нажмите кнопку **«+»** рядом с полем «Дней».
5. **Ожидаемый результат:** В поле «Дней» теперь `4`. Дата окончания пересчитана: `07.07 + 4 - 1 = 10.07`.
6. Нажмите кнопку **«+»** ещё раз.
7. **Ожидаемый результат:** В поле «Дней» теперь `5`. Дата окончания: `14.07`.

### TC-3.10 Ограничение максимального количества дней
1. В поле «Дата начала» введите: `01.01`.
2. В поле «Дней» введите: `365` (или больше).
3. **Ожидаемый результат:** Количество дней автоматически ограничивается до максимального (365 для 01.01). Дата окончания устанавливается на `31.12`. Если ввести больше — значение обрезается до максимума.

### TC-3.11 Дата окончания раньше даты начала
1. В поле «Дата начала» введите: `14.07`.
2. В поле «Дата окончания» введите: `07.07`.
3. **Ожидаемый результат:** Отображается сообщение об ошибке (красным текстом): «End date must be after or equal to start date». Кнопка «Сохранить» неактивна.

### TC-3.12 Пустые поля — кнопка «Сохранить» неактивна
1. Откройте форму нового отпуска.
2. Не вводите никаких данных.
3. **Ожидаемый результат:** Кнопка «Сохранить» неактивна (полупрозрачная, opacity 0.5).

### TC-3.13 Заполнена только дата начала — кнопка «Сохранить» неактивна
1. В поле «Дата начала» введите: `07.07`.
2. Поле «Дата окончания» оставьте пустым.
3. **Ожидаемый результат:** Кнопка «Сохранить» неактивна.

### TC-3.14 Поле «Дней» неактивно без даты начала
1. Не заполняйте поле «Дата начала».
2. Попробуйте нажать на поле «Дней».
3. **Ожидаемый результат:** Поле «Дней» неактивно (серый фон, полупрозрачное), ввод невозможен.

## 4. Отпуск — Предпросмотр (рабочие / всего)

### TC-4.1 Предпросмотр для рабочей недели
1. Введите дату начала: `07.07` (понедельник).
2. Введите дату окончания: `11.07` (пятница).
3. **Ожидаемый результат:** Блок предпросмотра показывает:
   - Рабочих дней: 5
   - Всего дней: 5

### TC-4.2 Предпросмотр с выходными
1. Введите дату начала: `11.07` (суббота).
2. Введите дату окончания: `13.07` (понедельник).
3. **Ожидаемый результат:**
   - Рабочих дней: 1 (только 13.07)
   - Всего дней: 3

### TC-4.3 Предпросмотр с государственным праздником
1. Введите дату начала: `01.01` (праздник).
2. Введите дату окончания: `08.01`.
3. **Ожидаемый результат:** Праздничные дни (01.01, 02.01, 03.01, 04.01, 05.01, 06.01, 07.01, 08.01 — в зависимости от встроенных данных) не считаются как рабочие. Рабочих дней = 0 (или 1, если 08.01 рабочий). Всего дней = 8.

### TC-4.4 Предпросмотр не отображается при неполных данных
1. Откройте форму нового отпуска.
2. Введите только дату начала: `07.07`.
3. **Ожидаемый результат:** Блок предпросмотра не отображается (скрыт).

## 5. Отпуск — Редактирование

### TC-5.1 Открытие формы редактирования
1. На экране «Отпуск» должна быть хотя бы одна карточка отпуска (создайте, если нет — см. TC-2.2).
2. Нажмите на карточку отпуска.
3. **Ожидаемый результат:** Откроется форма редактирования. Заголовок — «Редактирование». Поля заполнены текущими значениями дат. Кнопки: «Сохранить», «Отмена», «Удалить». Кнопка «Удалить» — красная.

### TC-5.2 Изменение даты начала при редактировании
1. Откройте форму редактирования (TC-5.1).
2. Измените поле «Дата начала» на другую дату (например, было `07.07`, стало `10.07`).
3. **Ожидаемый результат:** Дата окончания и количество дней пересчитываются автоматически.
4. Нажмите **«Сохранить»**.
5. **Ожидаемый результат:** Форма закрывается. В списке отпусков карточка обновлена с новой датой начала.

### TC-5.3 Изменение цвета при редактировании
1. Откройте форму редактирования.
2. Выберите другой цвет (например, оранжевый).
3. Нажмите **«Сохранить»**.
4. **Ожидаемый результат:** В списке отпусков полоса слева у карточки теперь оранжевая.

### TC-5.4 Отмена редактирования
1. Откройте форму редактирования.
2. Измените даты.
3. Нажмите **«Отмена»**.
4. **Ожидаемый результат:** Форма закрывается. Карточка отпуска в списке осталась без изменений (старые данные).

### TC-5.5 Аппаратная кнопка «Назад» при редактировании
1. Откройте форму редактирования.
2. Нажмите аппаратную кнопку **«Назад»**.
3. **Ожидаемый результат:** Форма закрывается (действует как «Отмена»). Изменения не сохраняются.

## 6. Отпуск — Удаление

### TC-6.1 Удаление отпуска — подтверждение
1. На экране «Отпуск» нажмите на карточку отпуска.
2. Нажмите красную кнопку **«Удалить»**.
3. **Ожидаемый результат:** Отображается блок подтверждения: «Удалить этот отпуск?» с кнопками «Да» (красная) и «Нет».

### TC-6.2 Подтверждение удаления
1. Выполните TC-6.1.
2. Нажмите кнопку **«Да»**.
3. **Ожидаемый результат:** Форма закрывается. Карточка отпуска удалена из списка.

### TC-6.3 Отмена удаления
1. Выполните TC-6.1.
2. Нажмите кнопку **«Нет»**.
3. **Ожидаемый результат:** Блок подтверждения исчезает. Остаётся форма редактирования с данными отпуска.

## 7. Отпуск — Граничные случаи

### TC-7.1 Два отпуска без пересечения
1. Создайте отпуск: `07.07` — `11.07`.
2. Создайте второй отпуск: `21.07` — `25.07`.
3. **Ожидаемый результат:** Обе карточки отображаются в списке. На годовом календаре в месяце июля дни 7-11 и 21-25 июля подсвечены цветами отпусков.

### TC-7.2 Два отпуска с пересечением
1. Создайте отпуск: `07.07` — `14.07` (бирюзовый).
2. Создайте второй отпуск: `10.07` — `18.07` (синий).
3. **Ожидаемый результат:** Обе карточки отображаются в списке. На календаре дни пересечения (10-14 июля) — какой цвет отображается, зависит от порядка обработки (первый найденный период). Возможна визуальная путаница — это нормальное поведение при пересечении.

### TC-7.3 Множественные отпуска (3 и более)
1. Создайте 3 отпуска в разных месяцах (январь, июль, декабрь).
2. **Ожидаемый результат:** Все три карточки отображаются в списке. На годовом календаре каждый отпуск подсвечен своим цветом.

### TC-7.4 Дата начала = дата окончания (отпуск на 1 день)
1. Создайте отпуск: `14.07` — `14.07`.
2. **Ожидаемый результат:** Кнопка «Сохранить» активна. Предпросмотр: 1 день. Карточка в списке: `14.07.2026 — 14.07.2026`.

### TC-7.5 Максимально длинный отпуск (весь год)
1. Создайте отпуск: `01.01` — `31.12`.
2. **Ожидаемый результат:** Предпросмотр показывает все рабочие/выходные/праздничные дни года. Кнопка «Сохранить» активна.

### TC-7.6 Отпуск, начинающийся в декабре и заканчивающийся в январе следующего года
1. Создайте отпуск: `28.12` — `05.01`.
2. **Ожидаемый результат:** Кнопка «Сохранить» активна. Предпросмотр корректно считает дни (декабрьские и январские).

### TC-7.7 Повторное открытие формы добавления после отмены
1. Откройте форму нового отпуска.
2. Введите данные: `07.07` — `11.07`.
3. Нажмите **«Отмена»**.
4. Снова нажмите **«+»**.
5. **Ожидаемый результат:** Форма открыта с пустыми полями (данные не сохранились).

### TC-7.8 Быстрое переключение между экранами
1. Откройте форму нового отпуска.
2. Нажмите «Отмена».
3. Сразу нажмите **«+»**.
4. Сразу нажмите «Отмена».
5. Сразу нажмите **«+»**.
6. **Ожидаемый результат:** Приложение не зависает, форма открывается корректно, поля пустые.

### TC-7.9 Сохранение отпуска с ошибкой в данных (кнопка «Сохранить» неактивна)
1. Откройте форму нового отпуска.
2. Введите дату начала: `14.07`.
3. Введите дату окончания: `07.07` (раньше начала).
4. **Ожидаемый результат:** Кнопка «Сохранить» неактивна. Сообщение об ошибке: «End date must be after or equal to start date».

### TC-7.10 Очистка поля даты и повторный ввод
1. В поле «Дата начала» введите: `07.07`.
2. Удалите содержимое поля (стиранием).
3. Введите: `14.07`.
4. **Ожидаемый результат:** Поле корректно обновляется. Дата окончания (если была заполнена) пересчитывается.

### TC-7.11 Ввод букв вместо цифр
1. В поле «Дата начала» попробуйте ввести буквы (например, `ab`).
2. **Ожидаемый результат:** Поле принимает только цифры (keyboardType="number-pad"). Буквы не вводятся.

### TC-7.12 Экран «Отпуск» при отсутствии отпусков (повторная проверка)
1. Удалите все отпуски (если есть).
2. Вернитесь на экран «Отпуск».
