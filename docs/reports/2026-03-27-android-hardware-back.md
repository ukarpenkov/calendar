# Android: жест и кнопка «Назад»

## Что изменено

В `src/app/App.tsx` добавлена подписка на `BackHandler` (`hardwareBackPress`). Для состояния `ready` обрабатываются экраны `month`, `month-error`, `settings` и `import-entry`: событие помечается как обработанное и состояние навигации обновляется так же, как при нажатии встроенных кнопок «Назад» (месяц и ошибка месяца → год, настройки → год, импорт → настройки). На корневом экране года, при загрузке, ошибке bootstrap и полноэкранной ошибке месяца поведение по умолчанию сохранено: система может закрыть активность.

## Что проверено

- `npm test` — все 10 наборов тестов проходят.
- ESLint для изменённого файла — без замечаний.
