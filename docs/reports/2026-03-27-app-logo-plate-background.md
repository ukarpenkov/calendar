# Фон-плашка для `AppLogo`

## Что изменено

- В `src/shared/ui/AppLogo.tsx` добавлена опциональная скруглённая плашка за всей композицией логотипа (цвет и тонкая обводка зависят от светлой/тёмной темы).
- Проп `withPlate` управляет включением; по умолчанию плашка **включена** для размера `large` (экран загрузки) и **выключена** для `small` (шапка года), чтобы не перегружать компактный блок.

## Что проверено

- Линтер для изменённого файла — без замечаний.

## Дальнейшие шаги

- При необходимости плашки в шапке года: `<AppLogo isDarkMode={…} size="small" withPlate />`.
- При желании вынести цвета плашки в общую палитру темы (`useAppTheme`) для полного совпадения с `palette.surface`.
