# Отступ контента месяца от верхней панели

## Что изменено

- В `shared/lib/ui/layout` задан `monthScrollPaddingTop`: сейчас **`contentStackGap * 2`** (40 px) — удвоенный базовый вертикальный шаг между блоками, чтобы контент месяца дальше ушёл от app bar.
- Ранее использовалось `Math.round(contentStackGap * 1.15)` (23 px); по запросу отступ увеличен ещё.
- У вертикального контента экрана месяца (`pageVerticalContent` в `MonthDetailScreen`) по-прежнему `paddingTop: layout.monthScrollPaddingTop`; то же для соседних страниц пейджера.

## Что проверено

- Линтер для затронутых файлов.
- `npm test` — все тесты проходят.

## Дальнейшие шаги

- При необходимости вынести множитель в именованную константу, если появятся другие экраны с похожей логикой.
