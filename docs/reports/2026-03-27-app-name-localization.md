# Локализация названия приложения

## Что изменено

- В `android/app/src/main/res/values/strings.xml` задано имя по умолчанию (не русская локаль): **Production calendar**.
- Добавлен `android/app/src/main/res/values-ru/strings.xml` с именем **Производственный календарь** для русского языка устройства.
- В `app.json` обновлён `displayName` на **Production calendar** (согласовано с дефолтным Android-ярлыком).

## Что проверено

- `AndroidManifest.xml` уже ссылается на `@string/app_name` — подхватывается выбор ресурса по локали системы.

## Дальнейшие шаги

- После смены языка системы перезапуск лаунчера или переустановка приложения может понадобиться, чтобы увидеть новый ярлык на некоторых прошивках.
