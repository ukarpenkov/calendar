# Перелистывание месяцев: новая схема анимаций

## Проблема и причины

Старый горизонтальный ScrollView одновременно управлялся через native momentum,
React month, отдельную очередь навигации, scrollX для параллакса и механизм
выравнивания/готовности. Стрелки меняли month до подтверждения native-перехода.
При этом страницы дальше одного месяца от React month заменялись пустыми View.
Если native-позиция и React month расходились, заголовок оставался прежним,
а физически видимая страница могла оказаться пустой.

Дополнительный путь к пустому экрану: opacity пейджера начиналась с нуля,
а подтверждение выравнивания зависело от scroll-события или ограниченного числа
асинхронных измерений. Успешная сборка и Jest-моки не доказывали совпадение этих
потоков на настоящем Android.

При повороте/возврате из фона пейджер пересоздавался; смена stack/split также
пересоздавала дерево месяца и изображение. Это усложняло восстановление состояния.

## Решение и выполненный план

1. Нативные жесты и горизонтальную анимацию выполняет Android ViewPager2 через
   react-native-pager-view 7.0.2. Версия закреплена в package.json/lockfile;
   используется уже включённая New Architecture React Native 0.84.
2. Заголовок, активные даты и доступность страницы обновляются по onPageSelected.
   React не посылает обратный scroll при подтверждении выбранной страницы.
3. Небольшой контроллер содержит подтверждённый месяц, цель стрелок и одну
   исполняемую команду. Следующая соседняя команда стартует по native idle.
   Прямой жест отменяет очередь стрелок. Повторное событие предыдущей страницы
   не подтверждает команду следующего месяца. Reduced Motion не ждёт momentum.
4. Все 12 страниц имеют постоянные ключи и собственное содержимое. Native pager
   держит ближайшие страницы через offscreenPageLimit=1. Пустых заглушек нет.
   Удалены пиксельные вычисления месяца, opacity readiness, измерения alignment,
   параллакс и масштабирование поверх native swipe.
5. При повороте сохраняются native pager, вертикальные ScrollView и ancestry
   баннера. MonthResponsiveLayout анимирует геометрию постоянных контейнеров
   через Reanimated LinearTransition. Декодированная картинка не заменяется
   из-за смены ориентации. Вертикальные позиции сохраняются отдельно для viewport.
6. При возврате из фона прерванная очередь сбрасывается к последнему
   подтверждённому месяцу, без пересоздания изображения. События размонтированного
   пейджера игнорируются. Новый вход из года получает свою initialPage.
7. Добавлены проверки реальных native страниц в scripts/test-month-paging.py;
   существующий scripts/test-month-layout.py проверяет повороты, блокировку,
   выбранный день и вертикальные позиции.

## Правила дальнейшего развития анимаций

- Native pager единолично владеет horizontal position. Декоративная анимация
  не должна менять выбранный месяц, состав страниц или скрывать весь календарь.
- Reanimated отвечает за открытие/закрытие, смену изображения и reflow. Длительности
  и easing находятся в shared/lib/ui/motion.ts; системный Reduced Motion учтён.
- Для нового эффекта баннера (наклон, вылет, поворот) менять визуальный контейнер
  в MonthResponsiveLayout. Сохранять его ключ, источник изображения и родителя.
- JS не получает покадровые scroll offsets. Если позже понадобится эффект,
  синхронный с жестом, onPageScroll подключать как UI-thread worklet и использовать
  только для transform. Не добавлять второй механизм выбора страницы.
- Nitro/свой Kotlin-пейджер сейчас не нужны: они добавили бы свой lifecycle,
  gesture arbitration и Fabric-интеграцию поверх уже существующего ViewPager2.
- Общая схема применима к другим экранам постепенно. Пейджер выбора отпуска
  использует прежний независимый контроллер и этой заменой не затронут.

## Проверки

- Полный Jest: 40 suites, 274 tests, 4 snapshots — успешно.
- TypeScript: npx tsc --noEmit — успешно.
- Release APK: :app:assembleRelease — успешно.
- Native Android, release на эмуляторе Medium_Phone: полный проход январь–декабрь
  и обратно, три быстрые стрелки в обе стороны, чередование направлений, Home/resume
  и следующий свайп — успешно (33 проверки).
- Native layout: многократные и быстрые повороты, выбор дня, блокировка/разблокировка
  в обеих ориентациях, поворот в фоне/при блокировке, прерывание свайпа блокировкой,
  сохранение вертикального смещения и смена выбранного дня — успешно (25 проверок).
  Отклонение сохранённых native bounds дня после поворота: 1 px.
- Во время первого прогона USB-телефон не был подключён. Последующая проверка
  на Android 17 описана в 2026-11-04-phone-animation-validation.md. Чтобы сохранить данные существующего
  эмулятора, тестировалась копия release APK, подписанная его debug-ключом;
  итоговый APK в android/app/build/outputs/apk/release подписан release-ключом проекта.
- Логи/артефакты native-прогонов: /tmp/calendar-paging-validation,
  /tmp/calendar-layout-validation. Заключительный прогон последней сборки:
  /tmp/calendar-paging-final.

Ни один механизм не даёт гарантии отсутствия всех будущих ошибок. Контракт native
selection + стабильные страницы уменьшает число источников состояния, а native
проверки покрывают реальные жесты, размеры и жизненный цикл Android.
