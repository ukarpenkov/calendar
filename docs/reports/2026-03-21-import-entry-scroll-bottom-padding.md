# Bug fix: нижний отступ на экране импорта JSON

## Проблема

На экране импорта года из локального JSON (`ImportEntryScreen`) последняя карточка с блоком «How this import works» при прокрутке до конца визуально прижималась к нижнему краю и к индикатору home gesture: недостаточный `paddingBottom` у `ScrollView` (было `safeAreaInsets.bottom + 32`).

## Изменения

- `src/pages/import-entry/ui/ImportEntryScreen.tsx`: `contentContainerStyle.paddingBottom` увеличен до `safeAreaInsets.bottom + 80` (как на экране настроек после предыдущего исправления).

## Проверка

- Линтер по изменённому файлу.
- Ручная проверка: прокрутить экран импорта вниз при выбранном файле и убедиться, что под последней карточкой есть запас над системной полосой.

## Связь с предыдущим отчётом

В отчёте `2026-03-21-settings-and-error-screen-bottom-inset.md` в «Дальнейшие шаги» уже упоминался экран импорта; это закрывает тот пункт для данного экрана.
