# Отчет: Этап 4. Year screen из SQLite

Дата: `2026-03-20`

Источник задачи: `docs/GLOBAL-DEVELOPMENT-PLAN.md`

## Что было сделано

Реализован следующий шаг после bootstrap: экран года больше не является заглушкой и теперь строится на основе календарных данных, загруженных из локального `SQLite`.

## Изменения

- `src/app/App.tsx`
  - после `seedBundledYearIfNeeded` приложение дополнительно перечитывает активный год через `getYearCalendar`
  - в ready-состояние передается полный `CalendarYear`, а не только номер года
- `src/entities/calendar/model/year-summary.ts`
  - добавлена подготовка данных для year view:
  - сводки по каждому месяцу
  - подсчет рабочих/нерабочих дней и часов
  - сборка недель для мини-календарей
- `src/entities/calendar/index.ts`
  - экспортирован summary-хелпер для использования в UI
- `src/pages/year/ui/YearHomeScreen.tsx`
  - временный экран заменен на годовой overview
  - добавлены верхняя панель, легенда, 12 карточек месяцев и мини-календари
  - данные берутся из `CalendarYear`, прочитанного из БД
- `__tests__/App.test.tsx`
  - тест обновлен под поток чтения года после bootstrap
- `__tests__/yearSummary.test.ts`
  - добавлен unit test для агрегирования month summary и построения недель

## Что проверено

- `npm test -- --runInBand __tests__/App.test.tsx __tests__/yearSummary.test.ts`
- `npx tsc --noEmit`
- IDE-диагностики по измененным файлам

## Результат

Сейчас приложение:

- поднимает БД и сидит bundled-данные при необходимости
- затем перечитывает активный календарный год из `SQLite`
- отображает `Year`-экран как overview из 12 месяцев
- показывает мини-календари, легенду и месячные totals на основе сохраненных данных
