# Отчет: Language Persistence

## Что изменено

- Добавлен `AppPreferencesRepository` поверх существующей таблицы `app_metadata` в `SQLite` без новой зависимости и без отдельной схемы настроек.
- В `LocalizationProvider` подключена гидратация сохраненного языка при старте приложения.
- Переключение языка теперь не только обновляет интерфейс в рантайме, но и сохраняет выбор пользователя для следующего запуска приложения.
- Добавлены тесты для репозитория настроек и для `LocalizationProvider`, чтобы отдельно проверить чтение сохраненного языка и запись нового значения.

## Что проверено

- Выполнен `npm test -- --runInBand`: `8/8` test suites passed.
- Выполнен `npm run lint`: без ошибок.
- Проверены IDE lints по измененным файлам: ошибок нет.

## Осталось при желании

- Аналогично сохранить между перезапусками выбор темы, чтобы поведение настроек было консистентным.
- При следующем развитии `Settings` можно объединить пользовательские preferences в один маленький слой настроек.
