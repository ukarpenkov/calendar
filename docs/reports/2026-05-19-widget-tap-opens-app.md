# Виджет: нажатие открывает приложение

## Что изменено

- На корневой контейнер виджета (`OverlapWidget`) в `CalendarWidgetLayout` для обоих состояний (нет данных / есть данные за сегодня) добавлено свойство **`clickAction="OPEN_APP"`** из библиотеки `react-native-android-widget`.
- В `CalendarWidgetTaskHandler` уточнён комментарий к ветке `WIDGET_CLICK`: открытие приложения обрабатывается нативно в `RNWidgetProvider` для действий `OPEN_APP` и `OPEN_URI`, к JS-п handler попадают только пользовательские `clickAction`.

## Что проверено

- По исходникам пакета `react-native-android-widget`: при `OPEN_APP` провайдер вызывает `getLaunchIntentForPackage` и `startActivity`, без запуска JS-задачи.
- Разметка виджета при обновлении через `registerWidget.tsx` использует тот же `CalendarWidgetLayout`, поэтому поведение едино для фона и для ручного обновления из приложения.

## Дальнейшие шаги

- На устройстве: после сборки снять виджет с экрана и добавить снова (или дождаться системного обновления), затем убедиться, что тап по области виджета открывает приложение.
- Учесть ограничение библиотеки: интерактивные области накладываются через `RemoteViews` начиная с **API 24** (`addClickableAreas` в `RNWidget.java`).
