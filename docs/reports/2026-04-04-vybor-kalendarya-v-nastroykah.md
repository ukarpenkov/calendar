# Выбор предзагруженного календаря в настройках

## Что изменено

- В блоке «Данные календаря» на экране настроек добавлен переключатель регионов встроенного производственного календаря на **2026** (Россия / Турция / Индонезия / Япония), по стилю как у языка интерфейса.
- Выбор сохраняется в SQLite (`app_metadata`, ключ `bundled_calendar_region`). При активном годе **2026** смена региона сразу подставляет соответствующий bundled JSON через тот же путь валидации и `replaceActiveYear`, что и при импорте.
- Сидирование пустой БД использует `resolveBundledCalendarRegionForSeed`: сначала сохранённый регион, иначе вывод из языка UI (`en` → набор `ru`, как и раньше по файлу `calendar2026.json`).
- Связка «смена языка → замена календаря» убрана: язык и регион календаря настраиваются независимо.
- Конфиг: `BUNDLED_CALENDAR_REGION_CODES`, `BUNDLED_CALENDAR_JSON_FILENAME_BY_REGION`; загрузка JSON по региону — `getBundledCalendarJsonForRegion`.

## Что проверено

- `npx jest --no-cache` — все тесты проходят.

## Дальнейшие шаги
