# Виджет: изображение на всю ширину (MIUI и др.)

## Что изменено

- В нативном `ImageWidget` библиотеки `react-native-android-widget` задан `ImageView.ScaleType.CENTER_CROP` вместо поведения по умолчанию (`FIT_CENTER`). Ранее картинка с фиксированным соотношением сторон (после `createScaledBitmap` с размерами 500×300 dp) вписывалась в область виджета с сохранением пропорций; на широких ячейках сетки (типично для Xiaomi/MIUI и растянутых по горизонтали виджетов) по бокам оставались пустые полосы.
- Добавлены `patch-package`, патч `patches/react-native-android-widget+0.20.3.patch` и скрипт `postinstall`, чтобы правка применялась после установки зависимостей.

## Что проверено

- Создание патча через `npx patch-package react-native-android-widget` после удаления `node_modules/react-native-android-widget/android/build` (иначе на Windows падает из‑за слишком длинных путей при `git add`).
- Сборка APK на устройстве не запускалась в этой сессии.

## Дальнейшие шаги

- Пересобрать приложение и проверить виджет на реальном Xiaomi: картинка должна заполнять ширину области виджета (с обрезкой по краям при сильном расхождении пропорций — ожидаемо для `CENTER_CROP`).
- При обновлении `react-native-android-widget` пересоздать или скорректировать патч при конфликте.
