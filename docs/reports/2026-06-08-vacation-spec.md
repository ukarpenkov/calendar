# Спецификация фичи «Отпуск»

## Что сделано

- Создана спецификация функционала «Отпуск» в `docs/vacation/spec.md`.
- Описан UI: кнопка пальмы на экране года, модальная форма управления отпусками (даты, комментарий, цвет), список с редактированием/удалением.
- Описана модель данных: таблица `vacations` в SQLite, тип `Vacation` в TypeScript, репозиторий с CRUD.
- Архитектура по FSD: новая фича `features/vacation-management`, расширение `entities/calendar`, изменения в `pages/year`, `widgets`, `shared/lib/db`.
- Отпуск реализован как **overlay** поверх существующего `DayType`, а не как новый тип дня.
- Виджет: поддержка картинки и подписи отпуска для текущего дня.
- Локализация: ключи на 5 языков (RU, EN, TR, ID, JA).
- Сформулированы 22 открытых вопроса по ролям: UX/UI (8), аналитик (4), архитектор БД (5), разработчик (5).
