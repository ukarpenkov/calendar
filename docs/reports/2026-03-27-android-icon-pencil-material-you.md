# Иконка Android и логотип хедера (Pencil)

## Что изменено

- В `pencil-new.pen` добавлена ось темы **`iconPalette`**: `brand`, `ocean`, `forest`, `sunset`, `mono` (вместе с существующей `appearance`: `light` / `dark`).
- Заведены цветовые токены для иконки: **`icon-bg`**, **`icon-card`**, **`icon-month-bar`**, **`icon-grid-cell`**, **`icon-accent`**, **`icon-gear`** — у каждого заданы значения для всех пар `(appearance × iconPalette)` по аналогии с динамическими палитрами Material You.
- Создан **векторный** переиспользуемый компонент **`kCRJe`** («Logo / Calendar + settings»): карточка календаря с сеткой, акцентной ячейкой (2 колонки во 2-й строке), полосой «месяца», иконка **Material Symbols Rounded** `settings` вместо растра с `O9QLP`.
- Собран фрейм **`F58CB`** «Android icon • Material You»: два ряда превью **432×432 px** (108 dp @xxxhdpi), макет **хедера года** (высота полосы **224 px** ≈ **56 dp** @xxxhdpi, логотип **148×161 px** ≈ **40 dp** высоты марки), подписи и заметка про экспорт adaptive-слоёв и **512×512** для Google Play.

## Что проверено

- Скриншот фрейма `F58CB` в Pencil: сетка палитр, тулбар с «2026», три масштаба марки без фона.
- Экспорт PNG (scale 2) в `docs/design-exports/` для узлов `OOmKs` (превью adaptive brand/light), `kCRJe` (марка), `4U2id` (макет хедера) — при успешном вызове MCP.

## Дополнение (2026-03-27)

- У всех инстансов `ref` на компонент `kCRJe` в фрейме `F58CB` увеличен масштаб относительно squircle-фона: адаптивные превью **314×340 px** (было 256×278); в макете тулбара и в ряду хедера марка **180×196 px** при расширенном контейнере `usrHF` **192×208 px** (было 148×161 / 160×170).
- Адаптивные превью: марка на **полную ширину** слоя **432 px**, высота **468 px** (пропорции 240∶260), вертикальное центрирование с лёгким клипом по `clip` родителя.
- Сближение с оригиналом `./image.png` (узел `O9QLP`): палитра **brand** — фон **#8FC9B6**, акцент **#F4978E**, ячейки **#BCCAD6**; первый ряд сетки **3** ячейки; шестерня **80×80**, смещение вправо-вверх и лёгкая тень; карточка **cornerRadius 26**, мягче тень; превью adaptive снова **276×299 px** (поля как у растра); тулбар/хедер **148×161** / **160×170**.

## Дальнейшие шаги

- В Android: разнести **background** (squircle + `$icon-bg`) и **foreground** (instance логотипа) в `res/mipmap-anydpi-v26`; цвета из токенов сопоставить с `Material You` / `monochrome` при необходимости.
- Для всех плотностей: **108×108 dp** на слой adaptive; при необходимости масштабировать макет 432 px или экспортировать отдельно per-density.
- При желании подогнать форму шестерни/вес под референс `image.png` (узел `O9QLP`) точечными правками `icon_font` или заменой на `path`.
