# Логотип приложения по макету Pencil (Material You)

## Что изменено

- В `src/shared/ui/AppLogo.tsx` вместо прежнего синего бейджа с текстом «2026 / Calendar» реализована графика из дизайна **Pencil**: фрейм **F58CB** («Android icon • Material You») ссылается на компонент **kCRJe** («Logo / Calendar + settings»).
- Разметка повторяет структуру макета: белая скруглённая карточка с полосой «месяца», сеткой дней (три ячейки в первом ряду, пять во втором с коралловым акцентом `#F4978E`, два ряда по пять квадратов), шестерня **Material**-стиля (`react-native-svg`, путь 24×24) в правом верхнем углу с тенью, цвета сетки и полосы как в `.pen` (`#BCCAD6`, `#E4EDF2`).
- Масштаб задаётся от ширины канваса 240 px; пресеты `large` / `small` сохранены. Для тёмной темы слегка усилена непрозрачность тени карточки.

## Что проверено

- `npm test` — все 10 suites / 35 тестов проходят.
- ESLint для изменённого файла — без замечаний.

## Дальнейшие шаги

- При необходимости выровнять размеры пресетов под точные dp из спецификации в F58CB (например 40 dp логотип в хедере).
- Отдельно: adaptive icon для Android (foreground/background, squircle) по той же спецификации — в нативных `android/` ресурсах.
