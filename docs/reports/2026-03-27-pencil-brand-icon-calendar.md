# Выравнивание превью иконки brand (light) с ocean в pencil-new.pen

## Что изменено

- Во фрейме `kAft8` (родитель инстанса `hfLy3` внутри превью **palette: brand • light**, узел `OOmKs`) структура приведена к той же схеме, что у **palette: ocean • light** (`Cs8x6`): добавлены две внешние строки сетки (`r3`, пять ячеек 22×24) выше и ниже инстанса компонента `kCRJe`.
- Для инстанса `hfLy3` добавлено переопределение `descendants`: у внутреннего ряда `OxaZb` (четвёртая строка сетки в карточке) установлено `enabled: false`, как у инстанса `lpYIP` в ocean-варианте.

MCP Pencil для этого файла недоступен (таймаут открытия / нет активного редактора), правка внесена напрямую в JSON `.pen`.

## Что проверено

- Файл `pencil-new.pen` успешно парсится как JSON.

## Дальнейшие шаги

- В Pencil визуально проверить превью brand light рядом с ocean light.
- При необходимости так же выровнять тёмный brand (`gprPl`), если эталоном остаётся только светлый ocean.
