# Отчёт: типографика итогов месяца

## Что изменено

- На экране месяца в блоке итогов подписи увеличены на 25%.
- Числа итогов выровнены по центру относительно подписей.
- Числам итогов сохранён крупный размер, визуально соответствующий числам дней в календаре месяца.
- В английской локали подпись `Non-working days` заменена на более короткую `Off days`.

## Что проверено

- Проверена диагностика `MonthDetailScreen.tsx` через IDE lints, ошибок не найдено.
- Проверена диагностика `en.ts` через IDE lints, ошибок не найдено.

## Дальнейшие шаги
