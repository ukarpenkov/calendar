# Скрытие "- 0 ч" для нерабочих дней

## Проблема
Для дней с нулевыми рабочими часами (выходные, праздники, отпуск) отображалось "Тип дня - 0 ч", что выглядело избыточно.

## Решение
Если рабочих часов = 0, показывается только тип дня без суффикса часов.

### Виджет (`CalendarWidgetLayout.tsx`)
- Отпуск: `"Отпуск - 0 ч"` → `"Отпуск"`

### Экран месяца (`MonthDetailScreen.tsx`)
- Отпуск: `"Отпуск - 0 ч"` → `"Отпуск"`
- Выходной/праздник: `"Выходной - 0 ч"` → `"Выходной"`
- Рабочий/сокращённый день: без изменений (часы отображаются как раньше)

## Файлы
- `src/widgets/CalendarWidgetLayout.tsx`
- `src/pages/month/ui/MonthDetailScreen.tsx`
