# Удаление карточки «Детали месяца» на экране месяца

## Что изменено

- На экране месяца (`MonthDetailScreen`) убрана верхняя карточка с eyebrow «Детали месяца», полным названием месяца и подзаголовком про SQLite — заголовок остаётся только в app bar.
- Из локализации удалены неиспользуемые ключи `month.header.eyebrow` и `month.header.subtitle` (en/ru).
- Интеграционный тест `App.test.tsx` проверяет наличие «Selected day» вместо удалённого «Month detail».

## Что проверено

- Линтер для изменённых файлов без замечаний.
- Запуск тестов: `npm test`.

## Дальнейшие шаги

- При необходимости можно дополнительно упростить экран (например, блок итогов), если появятся новые требования к UX.
