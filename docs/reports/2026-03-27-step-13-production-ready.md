# Шаг 13 глобального плана: UX, edge cases, тесты

## Что изменено

- **Bootstrap при ошибке SQLite/сида**: на экране сбоя инициализации добавлена кнопка «Повторить» (`Pressable` с `testID="app-bootstrap-retry"`), повторный запуск загрузки через счётчик поколения bootstrap в `useEffect`. Текст подсказки обновлён (EN/RU): сначала проверка хранилища и повтор, при необходимости перезапуск.
- **Ошибка месяца**: переход «Назад к году» оформлен как кнопка с ролями доступности и `testID="app-month-error-back"` вместо `Text.onPress`.
- **Тесты**:
  - импорт: високосный 2024 (366 дней, проверка `2024-02-29`), `INVALID_ROOT` для `null`, `INVALID_YEAR` для года вне диапазона;
  - `getCalendarDaysForMonth`: пустой результат при лишней записи в месяце (несовпадение числа дней с календарём);
  - `App`: сценарий повторного bootstrap после ошибки; сценарий `month-error` при повреждённом феврале и возврат на год.

## Что проверено

- `npm test` — все 41 тест проходят.
- `npm run lint` — в репозитории по-прежнему есть **существующая** ошибка `react-hooks/exhaustive-deps` в `MonthDetailScreen.tsx` (не затрагивалась этой задачей).
