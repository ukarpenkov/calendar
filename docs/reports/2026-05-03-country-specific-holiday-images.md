# Изоляция праздничных картинок по странам

## Что изменено

- Исправлен выбор изображений для праздников: специальные картинки больше не подбираются только по дате, а привязаны к паре «дата + название праздника».
- Убрано наследование картинки соседнего праздника для обычных выходных, чтобы, например, 2 мая в японском календаре не показывало изображение праздника 3 мая.
- Добавлены проверки, что российская картинка Дня Победы не попадает в японский выходной 9 мая, а японская картинка Дня Конституции используется только для самого праздника.

## Что проверено

- `npm test -- --runTestsByPath __tests__/holidayImages.test.ts`
- Проверка IDE-линтера для `src/entities/calendar/model/holidayImages.ts` и `__tests__/holidayImages.test.ts`.

## Дальнейшие шаги
