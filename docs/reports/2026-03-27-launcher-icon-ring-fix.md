# Иконка: мятная обводка (Pixel)

## Причина

1. **Старые `mipmap-*/ic_launcher*.png`** из шаблона React Native содержали **светло-бирюзовые/мятные** пиксели по краю (проверка выборки: цвета вроде `(115, 196, 189)`). Они могли подмешиваться в кэше лаунчера или на путях без adaptive XML.
2. На **Android 13+** при включённых **themed icons** система строит монохромный слой из adaptive-иконки; без явного **`monochrome`** силуэт часто получается «ломанным», с **светлым кольцом** вокруг тёмной заливки.

## Что изменено

- Добавлен **`drawable/ic_launcher_monochrome.xml`**: та же геометрия марки, что у foreground, **только белый силуэт на прозрачном** (для themed icons).
- Папка **`mipmap-anydpi-v33/`** с `ic_launcher.xml` и `ic_launcher_round.xml`: к background/foreground подключён **`<monochrome android:drawable="@drawable/ic_launcher_monochrome" />`** (для API 33+).
- Все **`mipmap-mdpi` … `mipmap-xxxhdpi`** файлы **`ic_launcher.png`** и **`ic_launcher_round.png`** перегенерированы: сплошной бренд **`#4A7D6E`** без старого мятного контура (для legacy и согласованности).

## Что проверено

- `:app:mergeDebugResources` — успешно.

## Дальнейшие шаги

- **Полная переустановка** приложения на устройстве (или очистка данных лаунчера), чтобы сбросить кэш иконки.
- Если кольцо останется: **Настройки → Обои и стиль** (Wallpaper & style) → отключить **Themed icons** / тематические иконки и проверить снова — тогда используется обычный adaptive-слой без системной перекраски.
