# Логотип: убрать ореол, крупнее в приложении

## Что изменено

### Android (`ic_launcher_foreground.xml`)

- В начало вектора добавлен **непрозрачный прямоугольник 108×108** с заливкой **`#4A7D6E`**, совпадающей с `ic_launcher_background`: слой foreground больше не остаётся прозрачным по краям, что уменьшает **цветной ореол / «обводку»** на некоторых лаунчерах при сборке adaptive icon.
- Масштаб марки увеличен с **0.303** до **0.39**, чтобы **календарь и шестерня** занимали большую часть круга.

### React Native (`src/shared/ui/AppLogo.tsx`)

- Плашка на splash (`withPlate`): единый фон **`#4A7D6E`** (как gprPl / иконка), убраны **hairline-бордер** и прежние `plateLight` / `plateBorder*`, из‑за которых вокруг логотипа читалась светлая рамка.
- Пресеты размера: **large** 100 → **124**, **small** 74 → **92**; у плашки меньше **padding** (14→10 по масштабу) и чуть меньше **радиус**, чтобы марка визуально крупнее.

## Что проверено

- `:app:mergeDebugResources` успешно.
- Линтер по `AppLogo.tsx` без замечаний.

## Дальнейшие шаги

- Если на Pixel ореол останется (тематизация лаунчера), можно дополнительно проверить с PNG `mipmap-*dpi` для API &lt; 26.
- При желании отдельно ослабить тени у `gearWrap` / `card`, если они дадут лишний контур на тёмном фоне.
