# Кнопка «назад»: стиль и анимация по нажатию

## Что изменено

- В `IconCircleButton` добавлен необязательный `variant`: `'default' | 'back'`.
- Для `variant="back"`: размер 56×56, прозрачный фон, два концентрических кольца (базовое из `palette.border` и акцент `#96DAF0`), анимация переключения и сдвиг иконки по горизонтали запускаются на **`onPressIn` / `onPressOut`** (аналог hover из макета, но для тача).
- Ripple на Android для варианта `back` отключён, чтобы не конфликтовал с кастомной анимацией.
- Подключено `variant="back"` для стрелки назад на экранах месяца, настроек и импорта; у заголовков настроек и импорта ширина правой заглушки в app bar увеличена до 56 px для симметрии с новой кнопкой.

## Что проверено

- Линтер по затронутым файлам — без замечаний.
- Полный прогон `npm test -- --runInBand` **не доведён до конца**: Jest после старта не выводил результаты тестов и был принудительно остановлен (зависание/отсутствие вывода). Повторить прогон локально при необходимости.

## Дальнейшие шаги

- При необходимости разобрать причину зависания Jest на этой машине (отдельный запуск с `--verbose` или узкий `--testPathPattern`).
- При желании подогнать цвет акцентного кольца под токены темы вместо фиксированного `#96DAF0`.
