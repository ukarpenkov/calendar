# Иконка приложения только в шапке экрана года

## Что изменено

- Компонент `AppLogo` убран из шапки `MonthDetailScreen` (месяц), `SettingsScreen` (настройки) и `ImportEntryScreen` (импорт JSON).
- На экранах настроек и импорта справа оставлен пустой `View` с прежними размерами `appBarTrailing` (36×36), чтобы заголовок по центру оставался визуально сбалансированным с кнопкой «назад» слева.
- На экране года (`YearHomeScreen`) логотип в шапке без изменений.

- Линтер по изменённым файлам — без замечаний.
