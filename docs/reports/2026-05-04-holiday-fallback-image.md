# Fallback-картинка для праздников

## Что изменено

- Для праздничных дней без отдельной привязки изображения добавлен общий fallback `assets/days_img/default_fiesta_fallback.webp`.
- Предзагрузка календарных изображений теперь учитывает этот fallback для праздников без персональной картинки.
- Добавлен unit-тест, который фиксирует, что такие праздники используют один общий праздничный fallback, а не месячную картинку.

## Что проверено

- `npm test -- holidayImages --runInBand`
- IDE diagnostics для изменённых файлов без ошибок.

## Дальнейшие шаги

- Если для конкретного праздника появится отдельный арт, его можно добавить в явную карту `date|holidayName`.
