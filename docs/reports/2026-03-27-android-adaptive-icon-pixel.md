# Адаптивная иконка под Pixel (круглая маска)

## Что изменено

- В `android/app/src/main/res/drawable/ic_launcher_foreground.xml` всё содержимое вектора обёрнуто в `<group>` с масштабом **0.63** от центра холста (54×54 в координатах viewport 108×108), чтобы клавиатура и шестерёнка попадали в **безопасную зону** адаптивной иконки (~66dp из 108dp) и не обрезались круглой маской лаунчера Pixel.
- В `android/app/src/main/res/values/colors.xml` цвет `ic_launcher_background` заменён с `#D4E2E8` на **`#FFFFFF`**, чтобы совпадать с белой «карточкой» на переднем плане и убрать заметное голубое кольцо по периметру круга.

## Что проверено

- Сборка `:app:compileDebugKotlin` (включая `mergeDebugResources` / `processDebugResources`) завершилась успешно.

## Дальнейшие шаги

- Пересобрать приложение и посмотреть иконку на устройстве; при необходимости подстроить коэффициент (например **0.58–0.65**) под субъективный размер.
- Старые **PNG** в `mipmap-*dpi` для API &lt; 26 по-прежнему со старым видом; при желании их можно перегенерировать из обновлённого вектора.
