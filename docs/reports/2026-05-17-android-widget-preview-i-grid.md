# Виджет Android: превью и сетка по умолчанию

## Что изменено

- В `calendar_widget_info.xml` целевой размер при добавлении виджета задан как **4×2** (`targetCellHeight="2"`), минимальная высота выровнена под две ячейки сетки (`minHeight="110dp"`).
- Для экрана выбора виджетов добавлен отдельный layout `calendar_widget_preview.xml`: светлый фон, **крупный** заголовок (22sp) и описание (16sp) тёмными цветами — контрастно на белой подложке лаунчера.
- В `calendar_widget_info.xml` указано `previewLayout="@layout/calendar_widget_preview"` вместо общего `calendar_widget`.

## Что проверено

- Локально сборку Gradle не запускали; изменения затрагивают только ресурсы Android (`xml`, `layout`).

## Дальнейшие шаги

- После установки APK проверить на устройстве: добавление виджета с размером по умолчанию 4×2 и отображение превью в списке виджетов.
- Подпись лаунчера над превью (имя приложения «Производственный календарь») задаётся темой лаунчера; при необходимости можно добавить отдельную bitmap-превью (`previewImage`), если понадобится полный контроль над миниатюрой.
