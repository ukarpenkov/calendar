# Вставка JSON-текста на экране импорта

## Что изменено

- На экран импорта добавлен отдельный блок для вставки готового JSON-текста.
- Поле ввода сделано многострочным и фиксированным по высоте примерно на 4 строки.
- Добавлена кнопка вставки текста из буфера обмена.
- Вставленный или введённый JSON проходит через тот же путь парсинга, валидации и нормализации, что и импорт из файла.
- При валидном JSON приложение автоматически переходит на шаг проверки (`Check`) с существующим preview перед подтверждением замены года.
- Добавлены переводы новых инструкций и кнопок для английского, русского, турецкого, индонезийского и японского языков.

## Что проверено

- Проверены IDE-диагностики изменённых файлов.
- Запущен точечный ESLint для экрана импорта и файлов локализации.
- ESLint завершился без ошибок; остался существующий warning про inline style в `ImportEntryScreen.tsx`.

## Дальнейшие шаги

- Можно дополнительно проверить поведение на Android-устройстве: копирование JSON из AI-чата, нажатие «Вставить текст», переход на шаг проверки и подтверждение замены года.
