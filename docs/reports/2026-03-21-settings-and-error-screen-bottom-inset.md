# Bug fix: нижний отступ на экране настроек и на экранах ошибки календаря

## Проблема

На экране настроек последняя секция («О приложении») визуально обрезалась у нижнего края при прокрутке: недостаточный `paddingBottom` у `ScrollView`.

На полноэкранных состояниях ошибки в `App` (невозможность загрузить календарь после старта, например повреждённые/неконсистентные данные в SQLite; отдельно — ошибка месяца) нижний отступ относительно safe area был меньше, чем у основных прокручиваемых экранов, из‑за чего контент мог казаться прижатым к системной навигации.

## Изменения

- `src/pages/settings/ui/SettingsScreen.tsx`: `contentContainerStyle.paddingBottom` увеличен с `safeAreaInsets.bottom + 32` до `safeAreaInsets.bottom + 80`.
- `src/app/App.tsx`: для блоков с `app.error.bootstrapTitle` и `app.error.monthTitle` `paddingBottom` увеличен с `safeAreaInsets.bottom + 24` до `safeAreaInsets.bottom + 56`.

## Проверка

- Линтер по изменённым файлам без новых замечаний.
- Ручная проверка на устройстве/эмуляторе: прокрутка настроек до конца; экраны ошибки после старта и при ошибке месяца — рекомендуется при следующем прогоне UI.

## Дальнейшие шаги

При повторении обрезания на других экранах со `ScrollView` (например импорт) можно выровнять нижний inset по тому же принципу или вынести общую константу в `shared`.
