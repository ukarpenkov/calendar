# Исправление перелистывания месяца кнопками

## Что изменено

- В `MonthDetailScreen` цели для кнопок «предыдущий / следующий месяц» берутся из пропа `month` (состояние в `App`), а не из локального `activeMonth`, который мог не успевать обновляться после программного `scrollToIndex`.
- При программном скролле по смене `month` сохраняется целевой месяц в `programmaticTargetMonthRef`; при первом колбеке `onViewableItemsChanged` с флагом программного скролла локальный `activeMonth` выставляется в этот целевой месяц (без повторного `onMonthChange`, родитель уже знает месяц). Так устраняется рассинхрон после того, как раньше колбек только сбрасывал флаг и выходил.

## Что проверено

- `npm test -- --testPathPattern=monthDetail` — тесты проходят.
- Линтер для изменённого файла — без замечаний.

## Дальнейшие шаги

- При необходимости добавить запасной синхрон по `onMomentumScrollEnd`, если на каких-то устройствах не придёт viewability после `scrollToIndex`.
