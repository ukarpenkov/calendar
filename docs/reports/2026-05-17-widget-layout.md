# Виджет: текст на изображении, без часов

## Что изменено

- Разметка `calendar_widget.xml`: убран внешний отступ `16dp`, чтобы контент виджета мог занимать всю доступную ширину без собственных полей приложения.
- `CalendarWidgetLayout`: одна композиция «картинка + текст поверх», скругление `16dp` у корневого контейнера и у `ImageWidget`, блок с рабочими часами и нижняя цветная полоса удалены.
- Подпись дня: при наличии локализованного названия праздника показывается только оно; иначе — «Выходной» / «Рабочий день» / «Сокращённый день» (и аналоги для en, tr, id, ja); для типа `holiday` без имени — запасной ярлык «Праздник» и т.п.
- `WidgetDayData`: добавлено поле `isShortened` для корректной подписи сокращённого дня при `type === 'workday'`; поле `workHours` из данных виджета убрано как неиспользуемое.
- Строки описания виджета в `values` и `values-ru` обновлены под новое поведение.

## Дополнение: прозрачный фон, текст только поверх изображения

- `calendar_widget.xml`: корневой `FrameLayout` с прозрачным фоном (`@android:color/transparent`) для начальной/превью-разметки.
- `CalendarWidgetLayout`: убран чёрный внешний контейнер; корень — `OverlapWidget` с `backgroundColor: #00000000`, чтобы по углам скругления была видна подложка лаунчера.
- Пустое состояние (БД не загружена): та же схема «фон-картинка + текст поверх», подставляется месячный плейсхолдер из `WIDGET_DEFAULT_IMAGE_BY_MONTH`, текст приглашения по центру с тенью.

## Что проверено

- Линтер для изменённых TS/TSX файлов — без замечаний.

## Дальнейшие шаги

- Сборка APK и визуальная проверка на лаунчере: системный виджет может добавлять собственные отступы к ячейке — это задаёт оболочка, не приложение.
