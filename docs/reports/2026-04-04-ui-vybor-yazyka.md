# UI выбора языка (шаг 3 плана)

## Что изменено

- `LanguageSwitch` (`src/shared/ui/LanguageSwitch.tsx`): источник опций — `AGREED_APP_LANGUAGE_CODES` из `agreedLanguagesAndBundledCalendars.ts`; вместо двух сегментов в ряд — вертикальный список кнопок на всю ширину; подписи — `Record<AppLanguage, string>`.
- В списке выбора каждый язык подписан **нативным автонимом** (`getLanguageNativeLabel` в `src/shared/lib/i18n/index.ts`: Русский, English, Türkçe, Bahasa Indonesia, 日本語), независимо от текущего UI. В подзаголовке строки настроек и в «О приложении» по-прежнему используется `getLanguageLabel` для названия **активного** языка на языке интерфейса.
- `SettingsScreen`: блок языка вынесен из узкого `SettingRow.trailing` в полноширинную колонку (заголовок + подзаголовок + список), чтобы пять языков помещались без переполнения; для списка — константа `LANGUAGE_SWITCH_NATIVE_LABELS`.

- `npm test` — все 11 suites / 47 тестов проходят.
