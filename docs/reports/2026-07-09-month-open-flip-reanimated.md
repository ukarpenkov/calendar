# Плавное разворачивание месяца из карточки года (Reanimated)

## Что изменено

- Подтверждено и доработано: разворачивание идёт через **Reanimated** (`withTiming` + `useAnimatedStyle` на UI thread), не через старый `Animated` API.
- Восстановлен FLIP-переход из нажатой карточки года: `YearHomeScreen` снова измеряет карточку через `measureInWindow`, `App.tsx` передаёт `originLayout` в `MonthDetailScreen`.
- Цели открытия (`openTargets`) вычисляются синхронно при монтировании overlay — без скачка на втором кадре из-за `useEffect`.
- Убран лишний `scrollToOffset` на mount (вызывал подёргивание во время анимации sheet).
- Контент календаря (FlatList) появляется с задержкой по `progress` (после ~45% разворота), чтобы тяжёлый layout не дёргал анимацию.

## Что проверено

- `npm test -- --testPathPattern="monthDetail|App.test"` — 18 тестов проходят.
- IDE diagnostics — без замечаний.

## Дальнейшие шаги

- Проверить на устройстве: тап по карточке месяца → плавное разворачивание из её позиции без рывков.
- При необходимости подстроить `OPEN_DURATION_MS` или порог появления контента (`0.45`).
