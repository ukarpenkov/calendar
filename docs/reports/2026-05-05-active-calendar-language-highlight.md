## Что изменено

- В переключателе языка добавлена отдельная подсветка активного bundled-календаря, когда выбранный язык не совпадает с регионом календаря.
- Экран настроек передаёт текущий регион календаря в переключатель языка, поэтому после выбора English прежний календарь остаётся видимым серой заливкой с обычной выбранной обводкой.
- Для календаря, загруженного из пользовательского JSON, подсветка bundled-региона не показывается, чтобы не обозначать его активным ошибочно.
- Серая заливка активного календаря отделена от цвета границ; граница остаётся обычной, без синего selected-акцента.

## Что проверено

- Проверены IDE-диагностики для изменённых файлов, ошибок не найдено.
