# Скругление углов логотипа в UI

## Что изменено

- В компоненте `src/shared/ui/AppLogo.tsx` растровый логотип обёрнут в `View` с `borderRadius` (≈20% от стороны, минимум 4 px) и `overflow: 'hidden'`, чтобы углы иконки визуально совпадали с привычной «приложенческой» формой на splash и на главном экране (все пресеты размеров).

## Что проверено

- Линтер для изменённого файла — без замечаний.

## Дальнейшие шаги

- При необходимости подобрать другой коэффициент скругления (сейчас единый для всех размеров через долю от `width`).
