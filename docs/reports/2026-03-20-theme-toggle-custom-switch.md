# Отчет: Кастомный theme toggle

## Что изменено

- Обычный переключатель темы на экране `Settings` заменен на кастомный `ThemeSwitch`.
- Новый компонент вынесен в `src/shared/ui/ThemeSwitch.tsx`.
- Визуально переключатель адаптирован под предоставленный HTML/CSS-референс: ночной режим со звездами и луной, дневной режим с голубым треком, солнцем и облаком.

## Что проверено

- Проверены IDE-lints для `ThemeSwitch` и `SettingsScreen`: новых ошибок нет.
- `npm run lint` по проекту по-прежнему падает только на уже существующей проблеме в `__tests__/App.test.tsx`.

## Дальше

- При необходимости можно довести анимацию еще ближе к веб-оригиналу: добавить лучи солнца, более сложную форму облака и плавную анимацию цвета трека.
