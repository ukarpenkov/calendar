# Что изменено

- JSON-импорт сохраняется в отдельный SQLite-слот `user_json_import` и больше не делает импортированный год активным сразу после сохранения.
- В схему SQLite добавлен источник календаря, чтобы bundled-календарь и JSON-календарь могли храниться отдельно.
- В переключатель языка добавлен пункт «JSON календарь» с одной иконкой календаря; при выборе он активирует сохраненный JSON-календарь, а язык интерфейса переключается на английский.
- Новый пункт переведен для всех языков приложения: English, Русский, Türkçe, Bahasa Indonesia, 日本語.

# Что проверено

- `npm run lint` завершился без ошибок, остались только существующие предупреждения.
- `npm test -- --runInBand __tests__/App.test.tsx __tests__/syncActiveYearWithBundledRegion.test.ts __tests__/localization.test.ts`: `syncActiveYearWithBundledRegion` и `localization` прошли; `App.test` завис в окружении Jest и был остановлен.
- Полный `npm test -- --runInBand` не прошел из-за окружения: `better-sqlite3` собран под другой Node.js ABI, а до правки тестового мока `App.test` падал на нативном `RNCClipboard`.
- `npx tsc --noEmit` не прошел из-за отсутствующих Node-типов для существующего теста с `fs`, `path` и `__dirname`.

# Дальнейшие шаги

- Пересобрать нативный модуль SQLite под текущую версию Node.js (`npm rebuild` или переустановка зависимостей) и повторить полный Jest.
- Отдельно стабилизировать `App.test`, если зависание сохранится после обновления тестового окружения.
