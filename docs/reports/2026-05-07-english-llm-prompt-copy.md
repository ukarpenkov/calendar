# Копирование английского LLM-промта

## Что изменено

- Обновлён `calendar_schema_and_prompt.txt`: текст схемы и промта переведён на английский язык.
- Обновлён `LLM_CALENDAR_PROMPT`, который используется кнопкой копирования на экране импорта, чтобы в буфер обмена попадал полный англоязычный текст.
- Русскоязычные примеры значений внутри `name_ru` заменены на англоязычные описательные значения, чтобы скопированный текст не содержал русских фрагментов.

## Что проверено

- Проверено, что кнопка продолжает использовать `Clipboard.setString(LLM_CALENDAR_PROMPT)`.
- Содержимое встроенной константы синхронизировано с текстовым файлом промта.

## Дальнейшие шаги

- При необходимости можно вынести генерацию `LLM_CALENDAR_PROMPT` из `calendar_schema_and_prompt.txt` в отдельный скрипт, чтобы исключить ручную рассинхронизацию.
