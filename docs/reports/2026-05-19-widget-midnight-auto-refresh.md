# Автообновление виджета после полуночи

## Что изменено

- Добавлен планировщик **AlarmManager** на локальную полночь (+ несколько секунд): по срабатыванию отправляется обычный `APPWIDGET_UPDATE` для `RNWidgetProvider`, что запускает уже существующий headless-путь `react-native-android-widget` и перерисовку виджета с актуальной датой из SQLite.
- После каждого срабатывания планируется **следующая** полночь (цепочка будильников).
- При **`BOOT_COMPLETED`** и **`TIMEZONE_CHANGED`** будильник пересоздаётся и виджет принудительно обновляется (перезагрузка устройства и смена часового пояса).
- В **`MainApplication.onCreate`** при старте процесса приложения также вызывается планирование полуночи (на случай, если пользователь давно не перезагружал телефон и будильник ещё не ставился).
- В **`App.tsx`** добавлено обновление виджета при переходе приложения в состояние **`active`** (подстраховка при возврате из фона в тот же календарный день).

Файлы: `CalendarWidgetAlarmScheduler.kt`, `CalendarWidgetAlarmReceiver.kt`, `CalendarWidgetBootstrapReceiver.kt`, правки `AndroidManifest.xml`, `MainApplication.kt`, `App.tsx`.

## Что проверено

- Сборка `:app:compileDebugKotlin` завершилась успешно.

## Дальнейшие шаги

- На устройствах с агрессивным энергосбережением иногда задерживаются фоновые alarm; при необходимости можно добавить напоминание пользователю об исключении приложения из оптимизации батареи или рассмотреть **`setAlarmClock`** / точные alarm (с отдельными разрешениями и ограничениями Google Play).
- После импорта JSON календарь в приложении меняется — при желании можно явно вызывать `updateCalendarWidget()` из обработчиков успешного импорта (сейчас основной сценарий — bootstrap и foreground).
