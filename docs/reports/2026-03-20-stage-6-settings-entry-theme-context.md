# Отчет: Stage 6 Settings entry + Theme context

## Что изменено

- Добавлен экран `Settings` со структурой из трех секций: `Calendar data`, `Appearance`, `About`.
- Подключен вход в `Settings` с главного экрана года через кнопку `⋮` в правом верхнем углу и overflow-меню.
- Поднят глобальный `AppThemeProvider` с общим состоянием темы и переключением `light/dark`.

- На экране `Settings` показан активный год из загруженного календаря и добавлен рабочий переключатель темы.
