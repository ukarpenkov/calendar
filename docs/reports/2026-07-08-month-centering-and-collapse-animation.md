# Центрирование месяца и анимация сворачивания

## Что изменено

- В `MonthDetailScreen` исправлено смещение контента при открытии месяца: `scrollX` инициализируется с `(month - 1) * pageWidth`, при монтировании выполняется `scrollToOffset`, при смене ориентации `scrollX` синхронизируется вместе с прокруткой FlatList. Параллакс больше не рассчитывается от нулевого offset при открытом неянварском месяце.
- Восстановлена анимация сворачивания на обычном `Animated` API (без Reanimated): при открытии лист плавно разворачивается из fallback-масштаба, при закрытии сворачивается в правый нижний угол с затемнением подложки.
- Удалён устаревший комментарий про Reanimated shared transition.

## Что проверено

- `npm test -- --testPathPattern=monthDetail` — 7 тестов проходят.
- IDE diagnostics для `MonthDetailScreen.tsx` — без замечаний.
