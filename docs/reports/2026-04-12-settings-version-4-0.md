# Синхронизация версии в настройках с релизом 4.0

## Что изменено

- В `src/shared/config/appDisplayVersion.ts` обновлена пользовательская версия приложения, отображаемая в экране настроек.
- Значение `APP_DISPLAY_VERSION` изменено с `3.0` на `4.0`, чтобы экран настроек совпадал с Android-релизной версией.

## Что проверено

- Подтверждено, что `SettingsScreen` использует `APP_DISPLAY_VERSION` для строки «Версия».
- Подтверждено, что `APP_DISPLAY_VERSION` теперь равен `4.0`.

## Дальнейшие шаги

- При следующем изменении релизной версии обновлять `android/app/build.gradle` и `src/shared/config/appDisplayVersion.ts` синхронно.
