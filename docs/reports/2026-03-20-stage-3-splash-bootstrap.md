# Отчет: Этап 3. Bootstrap приложения и Splash

Дата: `2026-03-20`

Источник задачи: `docs/GLOBAL-DEVELOPMENT-PLAN.md`

## Что было сделано

Реализован следующий шаг после `SQLite`-слоя: bootstrap приложения теперь скрыт за отдельным `Splash`-экраном, а после успешной инициализации приложение переходит на временный экран года.

## Изменения

- `src/app/App.tsx`
  - собран app shell с тремя состояниями: `loading`, `ready`, `error`
  - `seedBundledYearIfNeeded` по-прежнему остается единой точкой bootstrap-инициализации
  - при загрузке показывается отдельный `Splash`
  - после успеха открывается экран года-заглушка вместо технического сообщения о готовности storage
- `src/pages/splash/ui/SplashScreen.tsx`
  - добавлен отдельный splash-экран с логотипом, сообщением загрузки и safe-area отступами
- `src/pages/year/ui/YearHomeScreen.tsx`
  - добавлен временный домашний экран года, чтобы поток уже был `Splash -> Year`
- `src/shared/ui/AppLogo.tsx`
  - добавлен переиспользуемый простой логотип приложения
- `__tests__/App.test.tsx`
  - тесты обновлены под новые состояния bootstrap
  - отдельно проверяются `loading`, `ready` и `error`

## Что проверено

- `npm test -- --runInBand __tests__/App.test.tsx`
- `npx tsc --noEmit`
- IDE-диагностики по измененным файлам

## Результат

Сейчас приложение:

- показывает `Splash` во время инициализации локальной БД
- скрывает сид bundled `2026` за bootstrap-потоком
- после успеха переводит пользователя на экран года
- показывает отдельное error-состояние, если инициализация не удалась
