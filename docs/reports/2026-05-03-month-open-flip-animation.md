# Плавное открытие месяца из годового экрана

## Что изменено

- В `src/pages/month/ui/MonthDetailScreen.tsx` переход месяца переделан на FLIP-анимацию от измеренной карточки года: используются только `translateX`, `translateY`, `scaleX`, `scaleY` и `opacity` с `useNativeDriver`.
- Уменьшены длительности открытия и закрытия, чтобы переход ощущался быстрым и не перегружал слабые Android-устройства.
- В `src/app/App.tsx` сохранён исходный layout карточки при смене месяца внутри detail screen, чтобы закрытие возвращалось к исходной карточке вместо fallback-анимации.
- Inline styles в анимируемой странице месяца перенесены в `StyleSheet`, чтобы точечный ESLint проходил без предупреждений.

## Что проверено

- `npx eslint "src/app/App.tsx" "src/pages/month/ui/MonthDetailScreen.tsx"` — без ошибок и предупреждений.
- `npx tsc --noEmit` — не завершился из-за существующей конфигурационной проблемы тестов: TypeScript не видит Node-модули `fs`, `path` и глобальный `__dirname` в `__tests__/agreedLanguagesAndBundledCalendars.test.ts`.
- IDE diagnostics для изменённых файлов — без ошибок.

## Дальнейшие шаги

- Проверить переход на реальном Android-устройстве в debug/release, особенно на слабом устройстве и при быстром закрытии месяца.
- Отдельно настроить Node-типы для тестового окружения, чтобы общий `tsc --noEmit` снова мог проверять весь проект.
