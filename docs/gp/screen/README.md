# Google Play, календарь 2027

В каждой папке страны находятся готовая рекламная иллюстрация `feature-graphic.png` (1024 × 500) и три набора снимков **реального приложения в эмуляторе**:

- `phone/` — смартфон, 1080 × 1920 (форма отпуска кадрирована до 1026 × 1824);
- `7-inch/` — портретный планшетный режим, 1080 × 1920;
- `10-inch/` — альбомный планшетный режим, 1920 × 1080.

В каждой группе: обзор года, выбранный праздник страны, планирование отпуска. Праздники: Россия — Новый год (1 января), Турция — День национального суверенитета и детей (23 апреля), Индонезия — День независимости (17 августа), Япония — День основания государства (11 февраля), Мексика — День независимости (16 сентября). Интерфейс переключён на язык соответствующей страны.

`mockups/phone/` содержит дополнительные варианты с нарисованной рамкой смартфона и боковыми кнопками. Для полей **«Скриншоты для смартфона»** в Play Console используйте исходники из `phone/`: Google рекомендует загружать сам экран приложения без рамки устройства. Рамочные варианты можно использовать для просмотра и других маркетинговых макетов. Значок приложения здесь не менялся.

Иллюстрации созданы по отдельным запросам для каждой страны: элегантный бумажный календарь 2027 года на фоне узнаваемых местных пейзажей и праздничных элементов, с чистым пространством под интерфейс Google Play, без надписей и логотипов. Дальнейшая обработка — приведение к 1024 × 500 и оптимизация PNG.

Проверка формата, разрешения, соотношения сторон, числа снимков и размера файла:

```sh
python3 docs/gp/screen/validate_assets.py
```

Скриншоты сняты с release APK через `capture_emulator.py`; 7- и 10-дюймовые режимы получены переключением размера и плотности эмулятора. Изображения не содержат выдуманных экранов приложения.
