# Google Play, календарь 2027

В каждой папке страны находятся готовая рекламная иллюстрация `feature-graphic.png` (1024 × 500) и три набора снимков **реального приложения в эмуляторе**:

- `phone/` — смартфон, 1080 × 1920 (форма отпуска кадрирована до 1026 × 1824);
- `7-inch/` — портретный планшетный режим, 1080 × 1920;
- `10-inch/` — альбомный планшетный режим, 1920 × 1080.

В каждой группе: обзор года, выбранный праздник страны, планирование отпуска. Праздники: Россия — Новый год (1 января), Турция — День национального суверенитета и детей (23 апреля), Индонезия — День независимости (17 августа), Япония — День основания государства (11 февраля), Мексика — День независимости (16 сентября). Интерфейс переключён на язык соответствующей страны.

`mockups/phone/` содержит дополнительные варианты с нарисованной рамкой смартфона и боковыми кнопками. Для полей **«Скриншоты для смартфона»** в Play Console используйте исходники из `phone/`: [Google рекомендует загружать сам экран приложения без рамки устройства](https://developer.android.com/distribute/marketing-tools/device-art-generator). Рамочные варианты можно использовать для просмотра и других маркетинговых макетов. Пропорции интерфейса сохранены. Значок приложения здесь не менялся.

Иллюстрации созданы по отдельным запросам для каждой страны: элегантный бумажный календарь 2027 года на фоне узнаваемых местных пейзажей и праздничных элементов, с чистым пространством под интерфейс Google Play, без надписей и логотипов. Дальнейшая обработка — приведение к 1024 × 500 и оптимизация PNG.

Проверка формата, разрешения, соотношения сторон, числа снимков и размера файла:

```sh
python3 docs/gp/screen/validate_assets.py
```

Скриншоты сняты с release APK 14.0 (versionCode 15) через `capture_emulator.py`; 7- и 10-дюймовые режимы получены переключением размера и плотности эмулятора. Для Индонезии масштаб телефона немного уменьшен, чтобы шесть строк августа и название праздника полностью помещались на экран. Изображения не содержат выдуманных экранов приложения. В демонстрационных данных сохранён отпуск с 18 по 24 января 2027 года.

Проверка создаёт `assets-manifest.json` с точными размерами и весом каждого файла. Комплект содержит 45 снимков для загрузки, 5 иллюстраций для описания и 15 дополнительных рамочных макетов. Рекламные иллюстрации созданы встроенным инструментом ImageGen; экраны получены из запущенного приложения.

`preview.jpg` — обзор пяти стран. В `image-generation-notes.md` сохранены брифы для повторения иллюстраций и сведения о способе генерации.
