# Описания Google Play на 2027 год

Подготовлено 19 октября 2026 года по текущему коду проекта. Это тексты для версии с календарями 2027 года; соответствие уже опубликованной сборке не проверено.

- `en-US.txt` — английское название, краткое и полное описание.
- `store-listings.txt` — шесть языковых блоков для импорта переводов через ИИ: en-US, ru-RU, tr-TR, id, ja-JP, es-419.

В описанном пользователем окне импорта можно выбрать `store-listings.txt`. Совместимость этого конкретного файла с импортёром не проверена в Play Console. После распознавания проверьте распределение языков и трёх полей каждого блока в предпросмотре. Если понадобится ручной ввод, поля явно подписаны.

Английский текст — международный: он перечисляет пять встроенных стран, не обещая встроенный календарь США или Великобритании. Остальные тексты адаптированы для России, Турции, Индонезии, Японии и Мексики. Испанский вариант описывает именно мексиканский календарь; не следует представлять его как календарь праздников всех испаноязычных стран.

Перевод страницы привязан к языковым предпочтениям пользователя. Для показа отдельного предложения именно по стране используются custom store listings. Например, es-419 сам по себе не означает таргетинг исключительно на Мексику.

Лимиты Google Play: название — 30 символов, краткое описание — 80, полное — 4000. Длина каждого поля проверена скриптом. Локальные версии являются редакционными адаптациями; независимая вычитка носителями языка не проводилась.

Проверены наличие календарей 2027 года, выбор страны и языка, годовой и месячный вид, итоги месяца, отпуска, виджет, темы и импорт JSON. Часы описаны как значения выбранного календаря, без обещаний расчёта зарплаты или соответствия индивидуальному рабочему графику. Точность праздничных дат не была предметом этой работы.

Встроенного ИИ-чата нет: приложение позволяет скопировать запрос для внешнего сервиса и импортировать подготовленный JSON. После импорта пользовательского календаря интерфейс переключается на английский; это отражено в текстах. Функция Play Console «Импортируйте переводы с помощью ИИ» не описана как функция приложения.

Для следующего шага: подготовить скриншоты на каждом языке с местным календарём, экраном отпуска и виджетом. После публикации сравнить посещения страницы и конверсию в установку по странам. 250 скачиваний за год без этих показателей не объясняют причину низкого роста и не позволяют прогнозировать эффект нового текста.
