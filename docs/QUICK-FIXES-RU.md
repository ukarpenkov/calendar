# 🚀 Быстрые исправления дизайна - Календарь 2026

## ⚡ Top 5 критичных проблем

### 1️⃣ ШРИФТЫ СЛИШКОМ МЕЛКИЕ ❌

**Сейчас:**
- Номера недель: 5-6px 
- Дни: 6-7px
- Месяцы: 8px

**Должно быть (минимум):**
- Номера недель: 9sp
- Дни: 11sp
- Месяцы: 12sp
- Заголовок (2026): 24sp

**Почему:** Accessibility! Невозможно прочитать на реальном устройстве.

---

### 2️⃣ ЯЧЕЙКИ КАЛЕНДАРЯ 10×10px - НЕЛЬЗЯ ТАПНУТЬ ❌

**Material Design minimum:** 48×48 dp

**Решение:**
- Year view (компактный): минимум 24×24 dp
- Month detail: 44-48 dp

**Альтернатива:** Если не помещается - убрать детальные календари с year view, показывать упрощенные превью.

---

### 3️⃣ УДАЛИТЬ КАСТОМНЫЙ STATUS BAR ❌

**Проблема:**
- "9:41" - это iOS convention
- Нет системных иконок

**Решение:**
- Использовать нативный Android status bar
- Настроить только цвет иконок

---

### 4️⃣ МАЛО SPACING (ВОЗДУХА) ❌

**Сейчас:**
- Gap между месяцами: 4px
- Padding карточек: 4px

**Должно быть:**
- Gap между месяцами: 12dp
- Padding карточек: 12dp
- Padding экрана: 16dp

---

### 5️⃣ НАВИГАЦИЯ НЕПОНЯТНА ❌

**Проблема:**
- Как переключаться между годами?
- Зачем календарь и стрелки в header?

**Решение:**

```
┌─────────────────────────────┐
│  [☰]  2026  [ⓘ]      [⋮]   │ ← Top App Bar
└─────────────────────────────┘
      ↑ тап = выбор года
```

## 🎨 Цветовые проблемы

✅ Проверить все комбинации через WCAG AA (4.5:1)
⚠️ Text secondary может быть недостаточно контрастным на мелких шрифтах

```
Workday:   #FFFFFF (белый)
Weekend:   #E3F2FD (голубой)
Holiday:   #FFEBEE (светло-красный) + красная обводка
Shortened: #FFF9C4 (желтый) + желтая обводка
```

## 💡 Альтернативный подход для Year View

**Проблема:** Все 12 месяцев с полными календарями = слишком перегружено

**Варианты:**

### 🅰️ Mini-preview
- Показывать упрощенные превью месяцев
- Тап → открывается детальный экран месяца
- Heat map цвета (больше рабочих = темнее)

### 🅱️ Квартальный вид
- Показывать 3 месяца детально (текущий квартал)
- Навигация по кварталам: Q1, Q2, Q3, Q4

### 🅲️ Scrollable grid
- Вертикальный scroll
- По 1 месяцу в ряд
- Каждый месяц показан детально
