### Задача 2.2: Переработать Year View Layout
**Приоритет:** 🟠 ВЫСОКИЙ  
**Время:** 4-6 часов

#### Проблема:
После увеличения шрифтов и touch targets 12 месяцев не поместятся компактно

#### Решение 1: Vertical Scroll (РЕКОМЕНДУЕТСЯ)
```
┌─────────────────────────┐
│ App Bar                 │
├─────────────────────────┤
│ Legend                  │ ← sticky
├─────────────────────────┤
│ ┏━━━━━━━━━━━━━━━━━━━━┓ │
│ ┃ January             ┃ │ ← 1 месяц = 1 ряд
│ ┃ [полный календарь]  ┃ │   большие ячейки
│ ┗━━━━━━━━━━━━━━━━━━━━┛ │   48dp или 40dp
│ ┏━━━━━━━━━━━━━━━━━━━━┓ │
│ ┃ February            ┃ │
│ ┃ [полный календарь]  ┃ │
│ ┗━━━━━━━━━━━━━━━━━━━━┛ │
│          ⋮              │ ← scroll
└─────────────────────────┘
```

Преимущества:
- ✅ Большие touch targets (40-48dp)
- ✅ Читаемые шрифты
- ✅ Весь год виден
- ✅ Можно добавить статистику под каждый месяц

#### Решение 2: Grid 2×6
```
┌──────────────┬──────────────┐
│   January    │   February   │ ← row 1
│  [calendar]  │  [calendar]  │
├──────────────┼──────────────┤
│    March     │    April     │ ← row 2
│  [calendar]  │  [calendar]  │
├──────────────┼──────────────┤
        ⋮ scroll ⋮
```

С ячейками 24-28dp (компромисс)

#### Решение 3: Mini-preview + Detail on tap
```
┌─────┬─────┬─────┬─────┐
│ Jan │ Feb │ Mar │ Apr │ ← Small cards
│ 20w │ 18w │ 21w │ 20w │   с мини-инфо
│ 11f │ 10f │ 10f │ 10f │   БЕЗ календаря
└─────┴─────┴─────┴─────┘

Тап на месяц → Month Detail screen
Touch target: 80×60dp (весь блок)
```
